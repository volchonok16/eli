# Изображения и шрифты

`public/images/photos/` — визуальные изображения оформления. `public/images/*.svg` — иллюстрации деревьев. `public/api/files/products/` и `sale-points/` — локальные файлы для воспроизведения публичного каталога/базаров. Список и размеры — `ASSETS.json`.

Не выдавать иллюстрации за фотографии конкретного товара. На production использовать подтверждённые карточки и изображения из существующего хранилища. Для каталога рекомендуются качественные вертикальные снимки 3:4, например 1200×1600. Файлы другого формата не обрезаются, а показываются с полями.

Бинарные шрифты не включены. Подключение Google Fonts сохранено в HTML. Историю прав/лицензий сторонних ассетов этот архив не удостоверяет: сохранить лицензии библиотек и подтвердить допустимость используемых изображений/шрифтов перед выпуском. Системные иконки/материалы Apple в пакет не включены.
