# Eli — пакет передачи фронтенда

Актуальная версия дизайна от 13 ноября 2026 года. Передавайте весь ZIP целиком.

## Что это

Рабочий визуальный эталон всех страниц + редактируемые стили, эффекты и материалы для интеграции с существующим бэкендом. Это не готовая замена рабочего магазина: заказы, оплата, авторизация и отправка форм здесь демонстрационные.

Основа приложения `public/assets/eli-original.js` — минифицированная сборка React, полученная из публичного сайта. Исходных JSX/TSX-компонентов, исходного package.json приложения и sourcemap в этом пакете нет. Наши дополнительные CSS и JS представлены в читаемом виде в `src/`. Не нужно разрабатывать новый бэкенд. Рекомендуемый путь — перенести оформление и эффекты в исходный фронтенд существующего магазина, сохранив его API и бизнес-логику. Не редактировать вручную минифицированный bundle ради подключения реальных заказов.

## Быстрый запуск

1. Распаковать архив в обычную папку.
2. Установленный Node.js 18+; внешних npm-зависимостей нет, `npm install` не нужен.
3. В папке проекта выполнить `npm start` (или `node scripts/serve.mjs`).
4. Открыть http://127.0.0.1:8770 . Завершение сервера — Ctrl+C.

Если порт занят: `node scripts/serve.mjs --port 8780`.
Не открывать index.html двойным щелчком: приложение использует абсолютные пути и маршруты.
Шрифты загружаются через Google Fonts; без интернета будут системные замены.

После изменений в `src/`: `npm run build`, затем обновить браузер. `npm run check` проверяет файлы страниц и синтаксис скриптов. Здесь build только копирует редактируемый слой в `public/assets`; он не пересобирает React-приложение.

## С чего начать разработчику

1. `docs/INTEGRATION.md` — порядок переноса и что запросить у владельца бэкенда.
2. `docs/DESIGN.md` — согласованный вид, размеры, порядок CSS.
3. `docs/API-MAP.md` — наблюдаемые API-вызовы и демонстрационные данные.
4. `docs/ACCEPTANCE.md` — проверка перед выпуском.
5. `docs/ROUTES.json` — все 46 входных HTML-файлов/маршрутов.

## Структура

| Путь | Назначение |
|---|---|
| `src/design/styles/` | Редактируемые слои оформления |
| `src/design/scripts/` | Карусель, стеклянные эффекты |
| `src/preview/` | Демоданные, перехват API, вспомогательные DOM-правки и демо-уведомления |
| `public/` | Полная рабочая копия опубликованного интерфейса |
| `public/assets/eli-original.*` | Базовая сборка приложения; не исходный React-проект |
| `public/images/`, `public/api/files/` | Изображения и иллюстрации |
| `scripts/` | Запуск, копирование дизайн-слоя, проверка |
| `reference/` | Снимок мобильного каталога текущей версии |
| `MANIFEST.sha256` | Контрольные суммы содержимого архива |
